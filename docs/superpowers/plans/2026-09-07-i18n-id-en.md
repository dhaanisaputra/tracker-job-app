# Multi-bahasa ID–EN Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Seluruh UI app bisa diganti Indonesia↔English via toggle, persist via cookie, tanpa dependensi baru.

**Architecture:** Kamus flat `id`/`en` di `src/lib/i18n.ts` (parity EN↔ID ditegakkan compiler via `en: Dict`). Client pakai `useLang()` (context, init dari `<html data-lang>`); server components/actions pakai `cookies()` + `getServerLang()`. Toggle tulis cookie + `router.refresh()`.

**Tech Stack:** Next.js App Router, React 19, no new dependencies.

## Global Constraints

- **JANGAN commit maupun push dalam task apa pun.** Semua perubahan dibiarkan uncommitted untuk review owner. Langkah verifikasi menggantikan langkah commit.
- Nilai data/DB tidak diterjemahkan: 9 status, employment_type, work_arrangement, nama sumber, isi user.
- Format locale tanggal/angka out of scope, kecuali locale string `id-ID`→`en-US` dan prefix minggu `M`→`W` yang wajib ikut lang.
- `en` harus lengkap untuk setiap key `id` (compiler enforced via `en: Dict`); `npx tsc --noEmit` harus pass per task.
- Pola server: `import { getServerLang } from '@/lib/server-lang'; import { getDict } from '@/lib/i18n'; const t = getDict(await getServerLang())` lalu pakai `t['section.key']`.

```tsx
'use client'

import { createContext, useCallback, useContext, useEffect, useState } from 'react'
import { useRouter } from 'next/navigation'
import { getDict, parseLang, type Key, type Lang } from '@/lib/i18n'

type Ctx = { lang: Lang; t: (k: Key) => string; setLang: (l: Lang) => void }

const LanguageContext = createContext<Ctx>({ lang: 'id', t: (k) => k, setLang: () => {} })

function readInitial(): Lang {
  if (typeof document === 'undefined') return 'id'
  return parseLang(document.documentElement.dataset.lang)
}

export function LanguageProvider({ children }: { children: React.ReactNode }) {
  const router = useRouter()
  const [lang, setLangState] = useState<Lang>(readInitial)

  useEffect(() => {
    // eslint-disable-next-line react-hooks/set-state-in-effect -- once, sync from server-rendered attr
    setLangState(readInitial())
  }, [])

  const setLang = useCallback((l: Lang) => {
    document.cookie = `lang=${l}; path=/; max-age=31536000`
    try { localStorage.setItem('lang', l) } catch { /* ignore */ }
    document.documentElement.lang = l
    document.documentElement.dataset.lang = l
    setLangState(l)
    router.refresh()
  }, [router])

  const t = useCallback((k: Key) => getDict(lang)[k] ?? k, [lang])

  return <LanguageContext.Provider value={{ lang, t, setLang }}>{children}</LanguageContext.Provider>
}

export function useLang(): Ctx {
  return useContext(LanguageContext)
}
```

export function LanguageToggle({ dark = false }: { dark?: boolean }) {

      {(['id', 'en'] as Lang[]).map((l) => (

          type="button"
          onClick={() => setLang(l)}
          aria-pressed={lang === l}
          className={`px-2 py-2 uppercase transition ${lang === l ? 'bg-trailblaze text-white' : 'text-stone hover:bg-stone/10'}`}
        >
          {l}
        </button>
      ))}
    </div>
  )
}
